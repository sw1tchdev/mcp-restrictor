# @mcp-restrictor/policy

`@mcp-restrictor/policy` parses, validates, serializes, and evaluates the YAML
tool policy used by MCP Restrictor.

It exports `@mcp-restrictor/policy` and requires Node.js 22+. This project does
not yet document a stable embedding SDK contract; read the [policy reference](../../docs/policy.md)
and [root README](../../README.md) for the supported policy boundary.
