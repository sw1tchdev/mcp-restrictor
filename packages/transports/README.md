# @mcp-restrictor/transports

`@mcp-restrictor/transports` composes Restrictor's core filter with downstream
STDIO and HTTP(S) listeners plus STDIO, Streamable HTTP, SSE, and WebSocket
upstreams.

It exports `@mcp-restrictor/transports` and requires Node.js 22+. This project
does not yet document a stable embedding SDK contract; see the
[architecture](../../docs/architecture.md) and [root README](../../README.md).
