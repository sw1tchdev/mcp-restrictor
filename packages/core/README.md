# @mcp-restrictor/core

`@mcp-restrictor/core` owns MCP JSON-RPC filtering, tool discovery filtering,
tool-call authorization, duplicate-ID tracking, and audit-event types.

It exports `@mcp-restrictor/core` and requires Node.js 22+. This project does
not yet document a stable embedding SDK contract; see the [architecture](../../docs/architecture.md)
and [root README](../../README.md) for the current boundary.
